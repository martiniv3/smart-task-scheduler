

## Overview

Smart Task Scheduler is a full-stack web application for intelligent task planning, conflict detection, and automatic scheduling.

The system uses:

- Red-Black Tree scheduling engine
- Conflict detection
- Automatic free-slot search
- User authentication
- Multi-user task isolation
